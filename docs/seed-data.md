# Seed data → see [seed-actors.md](seed-actors.md)

The frozen contract (`siakang-pipeline/contract/api-v1.yaml`, `x-seed-data.doc`)
points here; the sprint plan's BE-01 criterion 3 names `seed-actors.md`. The
document itself lives at **[docs/seed-actors.md](seed-actors.md)** — one file, so
there is nothing to keep in sync.

It carries everything `x-seed-data` requires: credentials, wallet balances,
lat/lng, ratings, availability, catalog, config values, and the intended
haversine ordering for automatic matching.
